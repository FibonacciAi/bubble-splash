# GME 5D Chess

A playable, fan-made GameStop-themed multiverse chess experiment.

## Play

**https://fibonacciai.github.io/bubble-splash/gme-5d-chess/**

## Features

- Player Coalition vs. Short Syndicate
- Ryan Cohen, Roaring Kitty, GameStop, DRS, Pulte, Elon Musk, Donald Trump, Teddy, and household Players
- Standard chess rules including checkmate, castling, en passant, and promotion
- Timeline branching with limited Time Shards
- Future-line analysis, pawn-structure guidance, three AI strengths
- Cinematic and tactical board views
- Mobile touch controls and audio-safe startup

## Source

The game is self-contained and published from this folder. `index.html` verifies and reconstructs the game payload before launching it.

## Disclaimer

Unofficial fan-made parody. Fictional game mechanics; no allegation about any person or company. Not financial advice. GameStop and public-figure names are used as cultural references.
